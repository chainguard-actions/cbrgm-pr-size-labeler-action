# cbrgm/pr-size-labeler-action

Automatically labels pull requests based on their size, considering lines changed and number of files affected.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/cbrgm/pr-size-labeler-action](https://github.com/cbrgm/pr-size-labeler-action).
